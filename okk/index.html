Что подготовить

Без этого система будет «в молоко». 10 минут на сбор — и дальше всё пойдёт быстро.

1

Опорные материалы

Из модуля JTBD: бриф компании, сегменты, отстройка, продукты и цены. Плюс твой скрипт продаж.

2

Ключ Claude API

На console.anthropic.com → API Keys. Оплата по факту, один разбор — центы. Ключ хранится только у тебя.

3

Доступ к транскриптам

Откуда брать разговоры: авто-транскрипт звонков в CRM, записи Zoom, ККТУ, диктофон-бейдж для офлайн-встреч. Достаточно начать с одного источника.

Путь A · быстро, без кода

Готовый инструмент

Один HTML-файл, открывается в браузере. Важно: сначала его надо настроить под свой бизнес — иначе оценка будет общей, а не точной под твой продукт и нишу. Как именно — в блоке «Настрой под себя» сразу ниже.

  1. Открой инструмент → вкладка «⚙ Настройка»
  2. Заполни 8 полей о своём бизнесе (JTBD, продукт, скрипт, каскады…) — по гайду ниже или одним промптом-генератором
  3. Вставь свой ключ Claude API → «Сохранить»
  4. Вкладка «🎧 Разобрать звонок» → вставь транскрипт → карточка + дашборды

Путь A · настрой под себя

Скачать — мало. Инструмент надо настроить

«Из коробки» инструмент заполнен примером A-Players (карьерная консультация). Чтобы он давал точные рекомендации под твой продукт и нишу — замени пример на свою методологию. Это 8 полей во вкладке «⚙ Настройка». Два способа: вписать руками по таблице или сгенерировать одним промптом.

Способ 2 — сгенерируй настройку одним промптом (быстрее)

Скопируй промпт, вставь свои материалы (JTBD, позиционирование, скрипт, продукты, цены) → получишь готовый JSON. В инструменте: «⚙ Настройка» → «📥 Импорт JSON» → вставь → «Сохранить». Дальше можно чуть поправить руками.

Ты — методолог по продажам. Собери настройку для AI-инструмента контроля качества под МОЙ бизнес. Верни СТРОГО валидный JSON и больше ничего: { "profile": "сфера, продукт, тип продаж (B2B/B2C), средний чек, ЦА, tone of voice (ключевые и запрещённые фразы) — 3–5 предложений", "script": "мой скрипт по этапам: приветствие → контакт → программирование → выявление → усиление боли → презентация ХПВ → предзакрытие → возражения → закрытие", "critical": "критические ошибки, которые с ~90% губят сделку — списком", "phrases": "ключевые «фразы-убийцы» (характеристика→потребность→выгода), которые должны звучать в каждом звонке", "refusals": "причины отказов клиентов; дожимаемые пометь словом ДОЖИМ", "prodCascade": "в каком порядке я питчу продукты/тарифы", "finCascade": "порядок способов оплаты, приоритетный первым", "seg": "сегментация ABCDE / температура + подсказки по DISC (D/I/S/C)" } Мои материалы (вставь: JTBD, позиционирование, скрипт продаж, продукты и цены, отстройку): [ВСТАВЬ СЮДА свои опорные материалы]

Безопасно ли отдавать этот файл ученикам?

Да. Утечки данных нет. Инструмент работает в браузере ученика, на ЕГО ключе Claude API.
•Он не подключается ни к какой CRM и не содержит чужих ключей или доступов.
•Транскрипты ученик вставляет руками; всё хранится только у него в браузере (localStorage).
•Пример в настройках — просто редактируемый текст методологии, без клиентских данных и ключей.
Путь B · полная автоматизация · 7 шагов

Ведём тебя за руку

Это подробный разворот для Пути B — когда хочешь, чтобы всё работало само (звонки и встречи сами оценивались). «Пак» здесь — это okk-pack.zip, который ты скачал выше и загрузил в Claude Code (или в проект Claude). Каждый шаг называет конкретный файл из пака.

1

Собери «мозг» оценки под свой бизнес

В паке есть файл 03-blocks-prompts.md — там 9 готовых промптов, по одному на каждый блок методологии: (1) профиль бизнеса, (2) чек-лист скрипта по этапам, (3) критические ошибки, (4) ключевые фразы, (5) продуктовый каскад, (6) финансовый каскад, (7) причины отказа, (8) сегментация, (9) DISC.

Как делаешь: копируешь промпт → добавляешь свои материалы (бриф, скрипт, продукты) → получаешь текст → складываешь в config-template.json. Это методология, по которой AI оценивает звонки. (Если идёшь Путём A — это делает промпт-генератор из блока «Настрой под себя».)
2

Выбери способ работы

Без кода — готовый инструмент. С автоматизацией — пайплайн (шаги 3–4). Секреты только в переменных окружения.

3

Подключи источники транскриптов (только чтение)

amoCRM (читаем сделки и примечания), Zoom (recording:read), телефония. Тестируй на одной сделке — покажи себе, что данные читаются.

📄 Файл: 02-integrations-amocrm-zoom.md · ⚠️ см. безопасность ниже
4

Авто-передача продажных встреч из Zoom → ОКК

Встречи по продажам сами попадают в оценку (по теме/хосту/тегу). Событие Zoom «запись готова» → берём транскрипт → фильтр «это продажа?» → в оценщик.

5

Оценка звонка

Транскрипт + метаданные → оценка 6 этапов, риск срыва, ошибки, рекомендации по дожиму. Если риск → Telegram-алерт.

📄 Файл: 04-scoring-prompt.md (системный промпт + JSON)
6

Дашборды и воронка дожима

Собери выводы: дашборд с метриками и срезами, карточка звонка, касания/SLA, воронка дожима. В готовом инструменте это уже есть.

7

Предиктивная модель и ритм

Заведи метрики качества в еженедельную модель (Excel из пака). Ритм: планёрка (у кого что западает → ролевки), калибровка скриптов раз в 2 недели, ретроспектива чек-листа раз в квартал.

Слой безопасности · читать обязательно

ОКК ничего не сломает и ничего не утечёт

Главный принцип: только ЧТЕНИЕ

ОКК не создаёт, не меняет и не удаляет ничего в твоей CRM. Он только читает транскрипты и записи.
1.Отдельный токен только на чтение. В amoCRM — приватная интеграция с минимальными правами. НЕ админский токен. В коде разрешён только GET.
2.Ключи — в переменных окружения (.env, секрет-менеджер). Никогда в коде, репозитории, промптах или скриншотах.
3.Данные не уходят «в обучение». Свой Claude API-ключ (по условиям API данные не используются для обучения). В модель — только текст разговора. По желанию — маскирование телефонов/e-mail/ФИО.
4.Пилот сначала. Запусти на одной когорте/одном менеджере, проверь лимиты и корректность, потом расширяй.
5.Человек в контуре. ОКК помечает риск и советует — решение и действие за менеджером. Это co-pilot, не автопилот.
6.Тег «на дожим» в CRM — опционально. Единственная возможная запись, точечная и обратимая, только с твоего явного согласия. По умолчанию выключено — дожим ведём отдельным списком.
📄 Полный чек-лист безопасности — в файле 01-security-БЕЗОПАСНОСТЬ.md внутри пака. Правило №1: читаешь его первым.
