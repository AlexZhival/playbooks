Задача

Скрипт под реальный путь клиента

Сильный скрипт — не текст, придуманный отделом продаж, а технология под реальный путь клиента. Пройди CJM → AAARRR → 9 блоков → сборку → нейролевку и выйди с рабочим скриптом.

Что ты сдаёшь

  • CJM с эмоциональной кривой и точками провала
  • AAARRR-разбор + топ-3 бутылочных горлышка

  • DISC-шпаргалка для команды
  • Килер-чек-лист обязательных фраз (для ОКК)
  • Готовность защитить и провести ролевку

Финальный шаг · отработка

AI-тренажёр ролевок — собери под свой скрипт

Это «нейролевка» вживую. Отдельный тренажёр, который ты настраиваешь под свои продукты и свою ЦА: Claude играет живого клиента из твоей аудитории, а после каждой продажи даёт развивающий разбор по твоему скрипту, рекомендации с примерами фраз и ведёт твой прогресс от ролевки к ролевке. Можно голосом.

Что делает

  • Клиент из твоей ЦА про твой продукт (выбираешь, что продаёшь)
  • Настройка: воронка · психотип DISC · сегмент · сложность
  • Общение голосом — микрофон + озвучка ответов
  • Разбор по 9 этапам, балл до 100 и вердикт
  • Рекомендации с примерами фраз + выгрузка файлом
  • Вкладка «Прогресс» — преемственность между ролевками
1

Скачай и открой тренажёр

Открывается в браузере (лучше Chrome). Вставь ключ Claude API — клиентом управляет Claude.

2

Загрузи свою фактуру

4 блока: продукты · портрет клиента · база материалов (бриф, JTBD-сегменты, отстройка, кейсы, цены, возражения) · твой готовый скрипт. Вставляй текстом или прикрепляй файлами — именно это делает клиента живым и оценку точной. Индикатор «Готовность» подскажет, чего не хватает.

3

Проводи ролевки и расти

Отыгрывай продажи разным клиентам, забирай разбор и рекомендации, доводи навык до «зелёного» на вкладке «Прогресс».

🎙 Открыть AI-тренажёр ролевок
🔑 Нужен ключ Claude API (console.anthropic.com → API Keys) — оплата по факту, один диалог стоит центы. Ключ хранится только в твоём браузере. Голос работает лучше всего в Chrome.

Ускоритель: собрать каркас конфига промптом (необязательно)

Если лень заполнять руками — этот промпт соберёт каркас (продукты + портрет клиента + краткий скрипт) в виде JSON. Скопируй ответ модели → в тренажёре нажми «📥 Вставить конфиг (JSON)». Важно: всю базу материалов и полный скрипт всё равно вставь/подгрузи в тренажёр напрямую — именно verbatim-фактура делает клиента реалистичным, а разбор — точным.

Ты — опытный методолог по продажам. Помоги настроить AI-тренажёр ролевок под МОЙ бизнес: собери каркас конфигурации из моих материалов. Верни СТРОГО валидный JSON и больше ничего — без пояснений и без markdown: { "company": "как я представляюсь клиенту, 1 строка", "icp": "портрет идеального клиента: роль/должность, сфера, размер бизнеса, ситуация, ключевые боли, что для него важно и чего он боится — 3–6 предложений живым языком", "script": "мой скрипт по 9 блокам или ключевые этапы тезисно (приветствие → контакт → программирование → квалификация → выявление болей → презентация ХПВ → предзакрытие → отработка возражений → закрытие)", "products": [ { "name": "название продукта", "offer": "короткий оффер: что это и что клиент получает", "price": "цена", "value": "ключевой результат, ради которого покупают", "objections": "частые возражения к этому продукту через точку с запятой" } ] } Сделай icp конкретным и правдоподобным, а не общими словами. В products — по одному объекту на каждый мой продукт. Мои материалы (бриф, продукты и цены, JTBD-сегменты, отстройка, мой собранный скрипт): [ВСТАВЬ СЮДА свои опорные материалы и готовый скрипт]

Критерии готовности

Что значит «сделано хорошо»

Критерии

  • Не один скрипт, а 3 версии под сегменты
  • Каждый блок адаптирован под DISC
  • Есть ордена, опережающие возражения, каскады
  • Заполнен килер-чек-лист для ОКК
  • Прошёл нейролевку до «зелёного»

Формат защиты

Разбираем связку CJM → горлышки → блоки скрипта, которые их расшивают. Вплоть до живой продажи-демо. Готовность измеряется не «красивым документом», а пониманием логики.
