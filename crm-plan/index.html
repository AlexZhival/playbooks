Твои инструменты

Два инструмента — открываются в браузере

Работают на твоём ключе Claude API (вводится в браузере, хранится только у тебя). Без ключа — кнопка «Показать пример» покажет всё на демо-данных.

Инструмент 1

🧭 Конструктор воронки → ТЗ в CRM

Отвечаешь на вопросы о бизнесе → AI проектирует идеальную воронку по лучшим практикам.

  1. Этапы по результату + ЦКП, SLA, автоматизации amoCRM/Bitrix
  2. Карточка клиента (6 блоков + DISC), сегментация A–E, правила дожима
  3. Выгрузка: ТЗ в Excel + регламенты ОП + тех-ТЗ для вайбкодинга

Инструмент 2

📊 Калькулятор плана продаж → цифра

Прикрепляешь отчётность → инструмент читает её и считает план тремя методами.

  1. Компания → прикрепи Excel → «Прочитать и заполнить» (факт + бенчмарки)
  2. Медиаплан по каналам (C0/C1/CAC/ROMI) + отдел продаж (докрутка менеджеров)
  3. Итог: Commit / Target / Stretch + декомпозиция месяц→неделя→день

Как пройти

За руку — 8 шагов

1

Получи ключ Claude API

Один раз: console.anthropic.com → API Keys → создай ключ (sk-ant-…). Вставь его в инструмент — он сохранится только в твоём браузере.

Без ключа всё тоже смотрится: нажми «Показать пример» — работает на демо-данных.
2

Собери воронку в конструкторе

Открой конструктор, пройди 6 шагов о своём бизнесе → «Собрать воронку». Проверь этапы, карточку, сегментацию, дожим. Выгрузи ТЗ в Excel и нажми «Регламенты отдела продаж».

3

Настрой воронку в CRM

amoCRM или Bitrix — любая, это просто база («пластилин»), на которую надстраиваешь своё. Не переплачивай: базового тарифа хватит, дорогие «проекты» на старте не нужны. Claude можно подключить к CRM по API.

Заведи этапы по результату, обязательные поля на переходах и таймеры SLA — как в ТЗ.
4

Карточка клиента и сегментация

Заведи поля из 6 блоков + DISC. Сегмент A–E ставится по критериям потребность · срочность · деньги (A/B/C — целевые, D — нецелевой, E — не дозвонились). Часть полей (оценка звонка, риск, сегмент, DISC, причина отказа) заполнит ОКК автоматически.

5

Загрузи отчётность в калькулятор

Вкладка «Компания» → «📎 Прикрепить отчётность (Excel/CSV)». Google Sheets: «Файл → Скачать → .xlsx». Нажми «🔬 Прочитать и заполнить» — инструмент вытащит твои факт-цифры и предложит бенчмарки.

6

Разложи медиаплан по каналам

Вкладка «Медиаплан»: по каждому каналу трафика — бюджет, CPM/CPC, CTR, C0 (клик→заявка), C1 (заявка→оплата), чек → считает CPL, CAC, cash-in, ROMI. Добавляй/удаляй свои каналы. Формат (вебинар и т.п.) — это конвертер, а не канал.

7

Внеси отдел продаж

Вкладка «Отдел продаж»: добавь менеджеров (конверсия, средний чек, сделки/мес). Инструмент покажет резерв докрутки до лучших — сколько выручки добавит, если подтянуть отстающих.

8

Получи итоговый план

Вкладка «🎯 Итоговый план»: Commit / Target / Stretch, сходимость трёх методов и вердикт «брать / не брать». Декомпозируй Target по неделям и дням продавца.

Готово: у тебя ТЗ воронки для CRM и Target-цифра плана на месяц, которую не стыдно защитить.
Про ключ и приватность

Твой ключ — только твой

🔒 Как устроена приватность

1
Ключ Claude API вводишь в браузере. Он сохраняется локально у тебя и уходит только на api.anthropic.com по твоему ключу. Мы его не храним и не видим.
2
Файлы отчётности парсятся прямо в твоём браузере — никуда не заливаются. К Claude уходит только текстовая выжимка цифр (на твоём ключе).
3
В инструментах нет ничьих чужих ключей — каждый работает на своём. Оплата Claude — по факту, один расчёт стоит центы.
Правило: ключ никому не пересылай и не вставляй в общие документы. Он нужен только тебе и только в этих инструментах.

Критерии готовности

Чек-лист

  • Собрано ТЗ на воронку под твой бизнес (Excel)
  • В CRM заведены этапы по результату, обязательные поля и SLA
  • Заполнена карточка клиента + сегментация A–E + DISC
  • Загружена отчётность → подставлены факт-цифры и бенчмарки
  • Медиаплан разложен по каналам, виден ROMI по каждому
  • Внесены менеджеры, найден резерв докрутки
  • Посчитан план: Commit / Target / Stretch, сходимость ≤5%
Главная задача: приди с Target-цифрой на месяц, которую не стыдно защитить (методы сошлись ≤5%), и с ТЗ воронки, готовым к настройке в CRM.
